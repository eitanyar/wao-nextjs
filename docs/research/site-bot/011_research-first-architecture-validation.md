# Research-first architecture validation

## Scope

This deterministic cohort comparison uses only ASCII fixture inputs and mocked providers. It compares legacy Core-30 node generation with the research pipeline and page portfolio. It does not read or write `data/clients/` or `data/sites/`, call live providers, or make ranking claims.

## Fixed controls

- Clock: `2026-09-02T12:00:00.000Z`
- Provider calls: four mocked research operations per fixture
- Provider cost: `$0.07` per fixture
- Fixture inputs: `field.json`, `fixed.json`, and `hybrid.json`
- Command: `node scripts/compare-site-bot-architectures.mjs`

## Audit and safety gates

The comparison script accepts only the three named fixture identifiers. Its test snapshots the complete report, asserts that non-fixture input is rejected, and compares the top-level production data directory state before and after execution. The research pipeline persists only to an OS temporary directory created for each fixture and removes it before returning.

Escalation: None — all checks self-sufficient.
