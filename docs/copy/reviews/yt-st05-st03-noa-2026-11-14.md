## Fixes applied
1. 🔴/🟠 **Product name: «Ads Bot» → «בוט מודעות»** in both descriptions, with no article, as a proper name. Agreement stays masculine (פותח, לומד, בונה). The swap also fixes a bidi problem. Both third lines used to start with a Latin token, so YouTube's auto-direction would have set those lines left-to-right and moved the punctuation. Both lines now start with Hebrew. «Google Ads» is unchanged.
2. 🟠 **ST03: «סטודנטים» → «תלמידים»**, both times. It now matches the voice line «ומביא לו פחות תלמידים ויותר לקוחות».
3. 🟠 **ST05 title: there was no break between the two quotes.** «…לבד?״ תשלם על…» ran the question straight into the answer. I added a single-spaced em-dash: «…לבד?״ — תשלם על ״הרצפה מוצפת״». The text and the joke are unchanged.
4. 🟠 **ST05 description: tense.** «מהפניות שסימנת כאמיתיות» → «מהפניות שאתה מסמן כאמיתיות». On a brand-new account he hasn't marked anything yet, so the past tense didn't make sense. The present tense also matches ST03 («אתה רק מסמן»). I also added a breath comma before «ולומד».

## Checks
- **Length:** ST05 title is 62 characters (60 before the dash). ST03 title is 64. Both are within 70.
- **Names Google:** ST05 has «לגוגל» and ST03 has «בגוגל». Both pass.
- **Gershayim:** every quote is U+05F4 «״», which counts as a right-to-left character. That means it stays in place in the RTL flow and needs no mirroring, and the «?» inside «לבד?״» sits between Hebrew characters and displays correctly. There are no ASCII `"` or `'` characters.
- **Maqaf:** «ב־7» uses the real U+05BE. No other prefix touches a digit or a Latin word («חשבון Google Ads» needs no maqaf). There are no hyphens.
- **Spacing:** there are no double spaces in the Hebrew. The em-dash has single spaces.
- **Address:** singular masculine throughout. «אתם מחפשים עובדים?» is the caller speaking to the business inside quoted speech, so it's not a drift in how we address the reader.
- **Rules:** no price, no founder name, no hashtags. The link is alone on line 2.

## Writing upgrades (for waocopy)
- When a line of a description or post may display on its own (the first line, or the line after a link), start it with a Hebrew word, not a Latin product name or term. Could this rule make a great page worse? No: you can always reorder or add a Hebrew word without losing meaning.
- Use the actual name a product has on Hebrew surfaces. When unsure, flag it instead of falling back to the English working name. (Retire nothing; this sits under the cap.)
