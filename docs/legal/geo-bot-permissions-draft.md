# נספח הרשאות ונתונים — GEO Bot

**מסמך זה מחליף את סעיפי ההרשאות/נתונים במסמכים הבסיסיים (תנאי שימוש §4, מדיניות פרטיות §2, נספח עיבוד §5) עבור מוצר GEO Bot בלבד.**

---

### הרשאות וחיבורים (מחליף תנאי שימוש §4)

בחיבור ושימוש ב-GEO Bot אתה מצהיר שאתה מורשה לחבר את החשבון ולקבל המלצות עבור העסק שלך.

ההרשאות והחיבורים שהמערכת משתמשת בהם:

| שירות | סוג גישה | מה זה מאפשר |
|---|---|---|
| Google Search Console | קריאה בלבד | צפייה בנתוני חיפוש אורגני, ביצועי עמודים ושאילתות |
| Google Gemini API | קריאה/כתיבה (עיבוד) | ניתוח נתונים והפקת המלצות GEO |

**הערות חשובות:**
- **אין** חיבור ל-Google Ads ואין הרשאות כתיבה לכל חשבון פרסום.
- **אין** ביצוע פעולות בחשבון Search Console — קריאה בלבד.
- מסירת אישור/דחייה להמלצות מתבצעת באמצעות קישור `wa.me` (הודעה מוכנה מראש). **אין** אינטגרציה עם WhatsApp Business API ואין העברת נתונים ל-Meta.

באפשרותך לבטל את ההרשאה ל-Search Console בכל עת דרך Google או דרכנו. עם הביטול תיפסק יכולתנו לספק את השירות ביחס לאותו חשבון.

Google הוא ספק צד שלישי. גישתנו אליו כפופה לתנאיו, והוא רשאי לשנותה או להפסיקה. לא נישא באחריות להפסקה או שינוי כאמור, ובלבד שנפעל באופן סביר להודיע לך.

---

### מידע שנאסף ומעובד (מחליף מדיניות פרטיות §2 + חלקים רלוונטיים)

**מידע הרשמה וחיוב** — כמפורט במדיניות הפרטיות הבסיסית.

**מידע ספציפי ל-GEO Bot:**
- נתוני Google Search Console (שאילתות, עמודים, ביצועים) — קריאה בלבד.
- המלצות שהופקו, אישורים ודחיות שלך (לרבות דרך קישור wa.me).
- נתונים שאתה מזין לצורך הניתוח.

**אין איסוף או עיבוד של:**
- נתוני Google Ads / קמפיינים / תקציבים / הצעות מחיר.
- מזהי קליק (GCLID) או המרות אופליין.
- תוכן הודעות WhatsApp או מטא-דאטה של שיחות (הקישור הוא חד-כיווני בלבד).

**ספקי משנה רלוונטיים:**

| ספק | תפקיד | בסיס |
|---|---|---|
| Google Search Console | מקור נתונים (קריאה) | תנאי הפלטפורמה של Google |
| Google Gemini API | ניתוח והפקת המלצות | תנאי השירות בתשלום; DPA של Google Cloud |

---

### התחייבויות עיבוד (מחליף נספח עיבוד §4–§5)

חלות כל חמש ההתחייבויות של המחזיק כמפורט בנספח העיבוד הבסיסי, כולל:
- עיבוד לפי הוראה בלבד.
- בידוד מלא בין לקוחות.
- איסור אימון (עיבוד Gemini במסלול בתשלום).
- סודיות.
- אבטחה סבירה.

**ספקי משנה מאושרים ל-GEO Bot:** Google Search Console ו-Google Gemini API בלבד (בנוסף לספקי הסליקה והדוא"ל הכלליים).

**הבהרה לגבי WhatsApp:**  
השימוש בקישור `wa.me` (הודעה מוכנה מראש) אינו מהווה חיבור ל-WhatsApp Business API, אינו מעביר נתונים ל-Meta, ואינו יוצר יחס של עיבוד מידע מול Meta. הקישור משמש אך ורק כאמצעי נוח למשתמש לפתוח שיחה עם עצמו/צוותו. Meta אינה ספק משנה במסגרת שירות זה.
