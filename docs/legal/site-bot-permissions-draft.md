# נספח הרשאות ונתונים — Site Bot

**מסמך זה מחליף את סעיפי ההרשאות/נתונים במסמכים הבסיסיים (תנאי שימוש §4, מדיניות פרטיות §2, נספח עיבוד §5) עבור מוצר Site Bot בלבד.**

---

### הרשאות וחיבורים (מחליף תנאי שימוש §4)

בחיבור ושימוש ב-Site Bot אתה מצהיר שאתה מורשה להפעיל את השירות עבור העסק שלך.

ההרשאות והחיבורים שהמערכת משתמשת בהם:

| שירות | סוג גישה | מה זה מאפשר |
|---|---|---|
| Cloudflare Pages | אירוח ופריסה | פרסום האתר על תשתית Cloudflare Pages |
| Cloudflare DNS | ניהול רשומות | ניהול רשומות לכתובת האתר: תת-דומיין תחת wao.co.il, או דומיין הרשום על שם הלקוח, כאשר דומיין כזה מחובר בהסכמתו |
| Google Business Profile | גישת מנהל בהזמנת בעל העסק | עדכון פרטי העסק, מענה לביקורות ופרסום עדכונים; בעל העסק נשאר בעל הפרופיל |
| Alibaba Cloud (מודלי Qwen, אזור סינגפור) | עיבוד שפה | כתיבה וניתוח של טקסטים לאתר ושל תגובות לביקורות |
| DataForSEO | קריאת נתוני חיפוש | מילות מפתח, היקפי חיפוש ותוצאות חיפוש מקומיות |
| NeuronWriter | ניתוח תוכן | בדיקת תוכן מול ביטויי חיפוש |
| Google Places API | קריאת מידע עסקי ציבורי | שימוש במידע לצורך הבדיקה החינמית ולצורכי מחקר |
| ספקי סליקה ודוא״ל כלליים | חיוב ושליחת הודעות | עיבוד תשלום ושליחת הודעות שירות |

**הערות חשובות:**
- האתר מפורסם תחת תת-דומיין של WAO או תחת דומיין הרשום על שם הלקוח.
- אין חיבור ל-Google Ads, ל-Google Search Console, ל-GitHub או לכל פלטפורמת פרסום אחרת.
- אין הרשאות כתיבה לחשבונות פרסום.

**סיום השירות:**
- ניתן לבטל את השירות באופן מקוון בכל עת. הביטול נכנס לתוקף בתום החודש שכבר שולם.
- לאחר כניסת הביטול לתוקף, האתר נשאר זמין 30 ימים נוספים, ולאחר מכן מפסיק להיות זמין.
- הדומיין, אם קיים, ופרופיל העסק ב-Google נשארים בבעלותך. גישת הניהול של WAO לפרופיל העסק ב-Google מוסרת.
- אם חיוב חודשי נכשל ולא הוסדר לאחר ניסיונות חיוב חוזרים במשך 7 ימים, השירות מושעה: שירותי המערכת — עדכונים, ניהול, עמודים חדשים והבוט — נעצרים מיד; האתר הציבורי נשאר זמין 30 ימים נוספים, ולאחר מכן מפסיק להיות זמין.
- תשלום עבור החודש שלא שולם מחזיר את השירות לפעולה, ומועד החיוב החודשי נשאר ללא שינוי.

גישתנו לספקי הצד השלישי שלעיל כפופה לתנאיהם, והם רשאים לשנותה או להפסיקה. לא נישא באחריות להפסקה או שינוי כאמור, ובלבד שנפעל באופן סביר להודיע לך.

### מידע שנאסף ומעובד (מחליף מדיניות פרטיות §2 + חלקים רלוונטיים)

**מידע הרשמה וחיוב** — כמפורט במדיניות הפרטיות הבסיסית.

**מידע ספציפי ל-Site Bot:**
- פרטי העסק שאתה מוסר: שם העסק, שם בעל העסק, טלפון, כתובת דוא״ל, כתובת ואזור שירות, שירותים, מספר רישיון כאשר הדבר רלוונטי, שנות פעילות בתחום, תנאי אחריות ומה מייחד את העסק.
- תוכן וטקסטים שאתה מזין או שהמערכת מפיקה עבור האתר.
- מידע ציבורי על העסק שלך מ-Google ומתוצאות חיפוש.
- נתוני פרופיל העסק ב-Google, לרבות פרטים וביקורות, כל עוד WAO משמשת כמנהלת הפרופיל.
- פניות שלקוחות שלך משאירים דרך טופס יצירת הקשר באתר; WAO מעבדת פניות אלה מטעמך, אך ורק לשם העברתן אליך.
- הגדרות האתר, מבנה העמודים ונתוני פריסה.
- מזהה כתובת האתר ורשומות DNS הקשורות אליו.

**אין איסוף או עיבוד של:**
- נתוני Google Ads, לרבות קמפיינים ותקציבים.
- נתוני Google Search Console.
- מזהי קליק (GCLID) או המרות אופליין.
- נתונים מ-GitHub.
- תוכן מחשבונות צד שלישי אחרים, למעט המפורט לעיל.

**ספקי משנה רלוונטיים:**

| ספק | תפקיד | בסיס |
|---|---|---|
| Cloudflare Pages | אירוח ופריסת האתר | תנאי השירות של הספק |
| Cloudflare DNS | ניהול רשומות DNS | תנאי השירות של הספק |
| Google Business Profile | ניהול פרופיל העסק לפי הרשאת בעל העסק | תנאי השירות של הספק |
| Alibaba Cloud (מודלי Qwen, אזור סינגפור) | עיבוד שפה לכתיבה וניתוח | תנאי השירות של הספק |
| DataForSEO | נתוני חיפוש | תנאי השירות של הספק |
| NeuronWriter | ניתוח תוכן | תנאי השירות של הספק |
| Google Places API | מידע עסקי ציבורי | תנאי השירות של הספק |
| ספקי סליקה ודוא״ל כלליים | עיבוד תשלום ושליחת הודעות | תנאי השירות של הספק |

עיבוד באמצעות Cloudflare מתבצע בהתאם ל-Data Processing Addendum של Cloudflare ולתנאי השירות שלה.

---

### העברת מידע אל מחוץ לישראל

חלק מהספקים המפורטים לעיל מעבדים מידע מחוץ לישראל, לרבות בסינגפור ובארצות הברית. מועבר רק המידע הדרוש לביצוע הפעולה. בהצטרפותך לשירות אתה מסכים להעברה זו. הספקים מעבדים את המידע לפי תנאיהם המסחריים.

---

### התחייבויות עיבוד (מחליף נספח עיבוד §4–§5)

חלות כל חמש ההתחייבויות של המחזיק כמפורט בנספח העיבוד הבסיסי, כולל:
- עיבוד לפי הוראה בלבד.
- בידוד מלא בין לקוחות.
- איסור אימון: WAO לא תשתמש בנתוני לקוחות לאימון מודלים; העיבוד אצל ספקי המודלים מתבצע במסלולים מסחריים בתשלום, והוא כפוף לתנאיהם.
- סודיות.
- אבטחה סבירה.

**ספקי משנה מאושרים ל-Site Bot:** Cloudflare Pages, Cloudflare DNS, Google Business Profile, Alibaba Cloud (מודלי Qwen, אזור סינגפור), DataForSEO, NeuronWriter ו-Google Places API, וכן ספקי הסליקה והדוא״ל הכלליים.

**אושר על ידי עו״ד (2026-08-01):** אין צורך ב-DPA חתום בנפרד עם Cloudflare בשלב זה. המשפט שנוסף לעיל בטבלת ספקי המשנה מספיק. יש לבחון מחדש רק אם Cloudflare תדרוש הסכם נפרד בעתיד בהיקפים גדולים יותר.

**עדכון (2026-11-11):** נוסח זה מעדכן את הנושאים הבאים, וכולם ממתינים לאישור מחודש של עו״ד:

- כתובת האתר: תת-דומיין של WAO או דומיין הרשום על שם הלקוח.
- הרחבת המידע שנאסף ומעובד, לרבות עיבוד פניות מטופס יצירת הקשר באתר מטעם הלקוח.
- סעיף חדש בדבר העברת מידע אל מחוץ לישראל.
- נוסח חדש להתחייבות איסור האימון.
- תנאי סיום השירות והשעיית השירות בעקבות חיוב שנכשל.

**לבדיקת עו״ד:** נבקש לאשר: (1) את מספור הסעיפים המוחלפים בנספח העיבוד (§5 בפתיח לעומת §4–§5 בסעיף ההתחייבויות); (2) את הנוסח ״GitHub או לכל פלטפורמת פרסום אחרת״, שעשוי להשתמע ממנו ש-GitHub היא פלטפורמת פרסום; (3) האם Google Business Profile נחשב ספק משנה, בהינתן שהפרופיל בבעלות הלקוח ו-WAO משמשת בו כמנהלת בלבד.
